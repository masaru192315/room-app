# 開発ノート（DevNote）計画書

自分が作っているアプリの **経緯・目的・感想** を記録し、あとから振り返って **気付き** を得るための、無料・自作のノートアプリ。

## 1. 調査（AIエージェント10人）で分かったこと

| # | 観点 | 主な発見 | アプリへの反映 |
|---|------|----------|----------------|
| 1 | 主要ノートアプリ比較 (Notion/Obsidian/Evernote/Bear/Logseq) | 気付きに効くのは「日付軸のジャーナル」「リンク＋バックリンク」「絞り込み」 | タイムライン・`[[リンク]]`・バックリンク・フィルタ |
| 2 | 日本の人気日記アプリ (Day One/stoic./muute/Awarefy/Daylio) | 有料の中心は「定期レポート」「AIフィードバック」「同期」。KPTを組み込んだ振り返り専用アプリは見つからなかった | 週次インサイトを無料で提供し、KPT/YWTテンプレートを標準で入れる |
| 3 | ふりかえり手法 (KPT/YWT/4Ls/ADR) | 日次はYWTを3分、週次は4Ls＋Start/Stop/Continue、判断はADR-lite | 5種類のテンプレート |
| 4 | 気付きの仕組み（研究） | 「感情に名前をつける」には効果がある。過去ログを見返すと幸福感が上がった（CHI 2013） | 気分をワンタップで記録、「過去の今日」、問いかけ |
| 5 | 有料化ポイント | 同期・件数制限・エクスポート・テーマ・暗号化が有料に置かれやすい | 件数無制限・エクスポート・テーマはすべて無料。同期は将来 |
| 6 | UI/UX | 起動から1秒で書ける、自動保存、迷わない少ない機能 | ホームの先頭に入力欄、自動保存、5画面だけ |
| 7 | リンク・知識連携 | 「日誌＋wikiリンク＋バックリンク」が最小で効果的。全体グラフや厳密なZettelkastenは過剰 | グラフビューは作らない |
| 8 | 技術選定 | バニラJS＋IndexedDB＋PWA＋GitHub Pages なら0円。iOSはデータが消える恐れがあるのでエクスポートが必須 | ビルド不要の構成で、JSONとMarkdownの書き出しを初版から入れる |
| 9 | 不満点 | 重い・機能過多・データが取り出せない・同期で消える・広告・続かない | 軽量、ローカル優先、ゴミ箱、広告なし |
| 10 | 習慣化 | 連続日数の数字は義務感を生む。ヒートマップや週◯日目標のような「ゆるい」形がよい | 草カレンダー＋週目標（途切れても責めない） |

## 2. コンセプト

- **書くのは10秒、振り返りで気付く**：入力の負担は最小にし、気付きは振り返りの画面が受け持つ。
- **プロジェクト（＝作っているアプリ）単位** で、目的と経緯をタイムラインに残す。
- **データは自分のもの**：端末内（IndexedDB）に保存し、いつでもJSONとMarkdownで書き出せる。

## 3. 機能（v1 = 今回実装）

1. **ホーム**：気分（5段階）＋1行のクイック記録、今日の問い、過去の今日、草カレンダー、週目標
2. **ノート**：テンプレート5種
   - 🌱 目的・動機（なぜ作るか）
   - 📝 開発ログ（YWT：やったこと／わかったこと／次にやること）
   - 🔁 週次ふりかえり（4Ls＋Start/Stop/Continue）
   - ⚖️ 技術判断（ADR-lite）
   - 💭 自由メモ
3. **エディタ**：Markdown、自動保存、プレビュー、タグ、気分、`[[ノート名]]` リンク、バックリンク
4. **プロジェクト**：目的を常に表示し、時系列のタイムラインを出す
5. **気付き**：
   - 気分の推移グラフ（30日）
   - タグごとの気分の平均（相関であって因果ではない、と明記）
   - よく出る言葉
   - 「次にやること/Try」のうち、まだチェックが付いていない項目の一覧
   - ふりかえりの問いかけ
6. **設定**：テーマ（自動/ライト/ダーク）、週目標、エクスポート（JSON/Markdown）、インポート、ゴミ箱
7. **PWA**：ホーム画面に追加でき、オフラインでも動く

## 5. 技術構成

- HTML / CSS / JavaScript（ES Modules、ビルド不要、依存ライブラリなし）
- 保存先：IndexedDB（ノート・プロジェクト）、localStorage（設定のみ）
- オフライン：Service Worker
- 公開：GitHub Pages（無料）
