# 📓 開発ノート（DevNote）

作っているアプリの **経緯・目的・感想** を記録して、振り返りから **気付き** を得るためのノートアプリです。
無料・広告なし・登録不要で、データは自分の端末だけに保存されます。

> 10人のAIエージェントで既存のノート・日記アプリを調査し、その結果をもとに設計しました。調査結果と計画は [docs/PLAN.md](docs/PLAN.md) にあります。

## できること

| 画面 | 内容 |
|---|---|
| 🏠 ホーム | 気分ワンタップ＋1行で記録 / 今日の問い / 記録の草（週◯日目標） / 過去の今日 |
| 📚 ノート | 5種のテンプレート（目的・動機 / 開発ログ(YWT) / 週次ふりかえり(4Ls) / 技術判断(ADR) / 自由メモ）、入力に合わせて絞り込む検索 |
| ✏️ エディタ | Markdown・自動保存・`[[ノート名]]` リンクとバックリンク・`#タグ`・チェックボックス・集中モード |
| 🚀 プロジェクト | アプリごとに「目的」を常に表示し、経緯をタイムラインで見る |
| 💡 気付き | 1週間のまとめ / 気分の推移 / タグと気分の関係 / よく出る言葉 / やり残した「次にやること」 |
| ⚙️ 設定 | ダークモード / JSONバックアップと復元 / Markdownで書き出し / ゴミ箱 |

## 使い方

ビルドは不要です。静的ファイルを配信するだけで動きます。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

### スマホで使う（GitHub Pages・無料）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Branch を公開したいブランチ、フォルダを `/ (root)` にして保存する
3. 表示された URL をスマホで開き、「ホーム画面に追加」を選ぶと、アプリとして使える（オフラインでも動く）

## ⚠️ データについて

- データはブラウザの中（IndexedDB）に保存されます。サーバーには送られません。
- **特にiPhoneでは、ブラウザがデータを消すことがあります。** 設定画面の「バックアップ (JSON)」で定期的に書き出してください。
- 端末をまたいだ同期は、まだできません（今後の予定）。

## 構成

```
index.html          画面の骨組み
style.css           デザイン（ライト/ダーク）
js/app.js           画面とルーティング
js/db.js            IndexedDB の保存処理
js/templates.js     テンプレート・気分・問いかけ
js/markdown.js      Markdown 表示・[[リンク]] 抽出
js/insights.js      気付きの集計
sw.js               オフライン対応（Service Worker）
manifest.webmanifest PWA 設定
```
